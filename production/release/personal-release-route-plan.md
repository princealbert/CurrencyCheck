## 0. 决策结论（TL;DR）

| 优先级 | 平台路线 | 主体门槛 | 版号要求 | 结论 |
|---|---|---|---|---|
| 🥇 **主线** | **微信小游戏（个人）** | 个人可注册（同身份证≤5个） | 纯广告变现通常**不强制**版号，以软著+类目资质上线 | **最现实，现在就走** |
| 🥈 辅线 | CloudBase 静态托管 Web H5 | 无门槛（已有 dist + 加载门） | 无（web 托管不触发版号） | 公众号分发 / 长期 demo |
| 🥉 备选 | Steam 国际版 | 个人 $100/款（Steam Direct） | 不要求中国版号（面向全球） | 仅当愿意出海时启用 |
| ❌ 放弃 | TapTap 国服 / Steam 中国 / 华为·小米·OV·B站·4399 | 均需**公司 + 版号** | 必须版号 | 个人主体不可达 |

**一个关键澄清**：商业化游戏在国内的真正硬门槛是**版号（ISBN，国家新闻出版署核发）**，而版号**只有中国境内注册的公司能申请，个人 / 外资 / 境外公司均不可**。"备案"只是配套的域名/平台动作，不难、个人也能做——**难的是版号，而版号把个人挡在绝大多数商店门外**。因此所有"要版号"的大平台对你（纯个人）都是关门的，现实出路只剩上表三条。

## 1. 主线：微信小游戏（个人）— 详细

### 1.1 主体资格（已核实）
- **个人可以注册小游戏**：微信官方口径——国内个人及非个人（企业/个体/政府/媒体/其他组织）均可注册小游戏；同一身份证最多 **5 个**个人小游戏。
- **"未认证"对个人是正常状态**：微信认证（300 元/年）是企业/媒体才要的；你只需完成**微信实名**（你已有）。
- **个人主体不支持虚拟支付 / 内购**：只能走**流量主广告**变现（本作广告不卡进度，合规）。

### 1.2 上线硬性资质
1. **《计算机软件著作权登记证书》（软著）** — 微信小游戏上线硬性资质。
2. **所选类目对应资质** — 选「游戏 → 休闲游戏」类目，按平台指引提交。
3. **隐私保护指引** — 微信公众平台填写 + 审核通过；代码中接入隐私授权弹窗（`wx.requirePrivacyAuthorize`）。
4. **《游戏自审自查报告》** — 平台要求的自审材料（模板见 `production/release/self-review-report-template.md`）。

> **版号**：纯广告变现、无内购付费的小游戏，通常以「软著 + 类目资质」上线，**当前不强制版号**；若未来加入付费内购 / 虚拟货币购买，版号即硬门槛。**政策时有波动，提交前务必以微信官方社区最新公告为准**，并保留「被要求版号则转 Web H5 路线」的预案。

### 1.3 类目红线（必须规避）
- **绝不**选「金融 / 理财 / 财经 / 投资」类目（触发资金严审，且混淆于微信内「红包/赚钱版」克隆）。
- **绝不**在类目、简介、截图中出现「提现 / 赚钱 / 红包 / 收益 / 理财」。
- **教育/文化定位**通过玩法与文案体现（风格化母题 + 真实文化数据 + 静态汇率免责），不强挂「教育」类目（避免额外资质门槛）。

### 1.4 技术前置（依赖 v1.0.0-release.md）
- 当前 `wx-dist` ≈84 MB，**顶穿微信硬上限（主包≤4MB / 总包≤30MB）**，结论 NO-GO。
- 须先清 🔴 B1（资产全 CDN 化，4 处 base 常量 + build 排除规则）、🔴 B2（CDN 域名白名单）、🔴 B3（audio-smoke 断言）、⚠️ B4（汇率免责常驻 UI）。详见该文档 §1.4 / §5 / 附录 A。
- 清完 B1–B4 后，wx 包 ≈0.3MB，过审无虞。

### 1.5 时间线（甘特，软著是长板）
```
T+0   启动软著申请 ──────────────┐
T+0   填写隐私保护指引 + 起草自审报告  │
T+0    engineering 启动 B1 CDN 化      │（≈1 周）
T+30~60 软著下证 ◄──────────────────┘（普通免费，周期 1–2 月；加急更短）
T+材料齐 提交提审 → 审核 1–7 天 → 体验版 → 灰度 1–3 天 → 全量
```
**总周期瓶颈 = 软著（约 2 个月），现在就该启动。**

## 2. 辅线：CloudBase 静态托管 Web H5

- **现状**：`minigame/dist/` 已现产（含加载门版本，已剔除环游帧），是自包含静态站（`index.html` + `game.js` + `assets/`），相对路径可放任意子目录。
- **部署目标**：`https://<envId>-<appId>.tcloudbaseapp.com/Currencycheck/index.html`（永久子域，免备案）。
- **用途**：公众号文章挂链接、长期稳定 demo、内测分发；无商店门槛、无版号要求。
- **约束**：须保持「个人、非商业化」定位，不将其作为商业游戏产品在大规模渠道铺开。
- **额度**：旧 env `d9gwvua435e6368fc` 免费额度若用完，用「微信 AI 应用及线上工具小程序成长计划（2026 全年）」开**新免费个人云环境**承接静态托管。
- **账号提示**：WorkBuddy 侧的 CloudBase 连接器登录账号 ≠ 托管你 MVP 的账号，推不上去；正式推送在你 Mac 用 `tcb login`（正确账号）后 `tcb hosting deploy ./minigame/dist Currencycheck -e <envId>`。

## 3. 备选：Steam 国际版（仅当出海）

- **资格**：个人 $100/款（Steam Direct，售卖满 $1000 可退），即可上架。
- **版号**：**不要求中国版号**（不在中国大陆运营，面向全球发行）。
- **限制**：① 大陆访问不稳定 / 常被墙；② **不能向中国大陆用户宣传推广**，否则仍可能追责 —— 等于"出海"，不是国内分发。
- **适用**：仅当你接受"只做海外、国内不推广"时启用；与主线/辅线不冲突，可并行。

## 4. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 微信政策波动（突然要求版号） | 主线阻断 | 保持纯广告、不留内购；软著提前备齐；必要时转 CloudBase Web H5 辅线 |
| wx 包体积顶穿（B1） | 提审失败 | 资产全 CDN 化（v1.0.0-release §2 路线 A），已论证零质量损失 |
| CDN 域名未备案 / 白名单漏配（B2） | 真机拉取失败 | 路线 A 域名须 ICP 备案 + 微信后台加白名单（图像 downloadFile / 音频媒体域名） |
| CloudBase 额度耗尽 | 辅线不可用 | 微信 AI 成长计划开新免费 env |
| 合规误读为"赚钱/投资" | 下架 / 审核拒 | 全量文案规避资金措辞；类目避金融；详情/对白零投资用语（v1.0.0-release §5） |
| 36 张母题 PNG 像素级合规 | 提审驳回 | 人工目检：无真钞复刻、region 非国旗（v1.0.0-release §1.5-B） |
