- **渠道**：中国版权保护中心官网 `https://www.ccopyright.com.cn`（或地方版权服务中心代办）。

## 7. 版本迭代与软著的关系（常见疑问）

**结论：一次登记，长期有效；小版本迭代不重复申请。**

- **软著保护的是「该软件作品」，不是某个具体版本。** 为 V1.0 登记一次后，这份证书即证明你拥有该软件的著作权，覆盖其整个生命周期。
- **日常版本更新（bug 修复、加关卡、UI 调整、平衡性改动、新增内容包）** → **不需要重新登记**软著，原证持续有效。
- **微信小游戏每次版本更新重新提审时**，平台要的是「你有权发布这个游戏」的证明，通常**仍用最初那一份软著证**，无需换新证；但**自审自查报告（或内容变更说明）应随新版本更新**（见 `self-review-report-template.md`），因为新版本内容变了，需重新确认合规。
- **只有「实质是新软件」时才建议补登新证**（保护力考量，非平台强制）：
  - 更换核心引擎 / 重写底层架构；
  - 游戏改名换皮、核心玩法根本性改变；
  - 代码与原登记版本差异过大，原证对新版本的保护力被质疑。
- **版本号写法**：首次登记可写 `V1.0`；日后大改可加登 `V2.0` 或新名称，但小版本（V1.1、V1.2…）无需动软著。

> 实务提示：软著是**自愿登记**，法律未要求每次发版都重新登记。把精力放在「V1.0 一次登记 + 每次版本更新更新自审报告」即可，合规成本最低。
