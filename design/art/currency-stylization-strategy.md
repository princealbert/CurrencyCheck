## 0. 执行摘要（核心论点）

用户的北极星指标（成功标准）已明确：**迁移识别（transferable recognition）**——玩家在现实里见到真钞 / 真币能认出。本策略所有技法都服务于「玩家把游戏 token 与真实钞券对上号」，而不仅仅是「游戏内好看、能配对」。

用户的原话锚点：「我最初的目标是通过这个游戏认识各国的货币，哪怕是特征还原，再看到他国货币的时候，就真的能认出来。」因此风格化必须是 **漫画式保真（caricature fidelity）**：抓住真身最 salient（突出）的特征——主导色相、中央母题类别、面额数字、区域形状——并粉彩化重演绎；**弱化**像素级纹理、写实光影、国徽精确造型等非关键细节。抽象掉可辨识锚点 = 迁移失败，是本策略的红线。

用户的困惑本质是：**「不能用真币图，却要让每种货币一眼可辨、唤出真币气质、并在现实中可迁移」**——这是可被美术技法正面解决的命题，而非矛盾。

答案是建立 **「四层身份模型」**，让识别信息**逐层冗余、互不依赖颜色**，且每一层的锚点都回指真实钞券：

| 层 | 传递的信息 | 载体 | 是否依赖颜色 |
|----|-----------|------|------------|
| ① 形状层 | 大洲 | 区域双编码形状（圆角矩形 / 六边形 / 菱形） | 否（靠轮廓） |
| ② 母题色层 | 币种气质 | 从真币提取并软化的风格化主色 | 是（但有形状兜底） |
| ③ ISO 码层 | 无歧义身份 | `USD` / `EUR` / `JPY` / `CNY` 文本 | 否（靠文字） |
| ④ 面额层 | 层级 | 环数 / 尺寸 / 微光泽 + 数字 | 否（靠数量与字） |

**关键设计纪律**：颜色在所有层中都不是「唯一」识别通道。即便色弱用户关闭母题色，①+③+④ 仍可 100% 辨识。这正是合规信封内「还原气质却不复制」的可执行解法。

## 1. 设计信封回顾（硬约束，作为不可逾越边界）

- ❌ 禁用真实纸币 / 硬币图样（版权 + 《人民币管理条例》反假币 + 微信审核三重风险）。
- ✅ 只用 **风格化几何货币母题**（自有原创资产）。
- ✅ 以 **ISO 4217 代码** 中立标识，弱化国旗。
- ✅ 区域双编码（色弱友好）：美洲 = 圆角矩形 + 金 `#E0B15E`；欧洲 = 六边形 + 蓝 `#5B8FB0`；亚洲·非洲 = 菱形 + 绿 `#87A878`。
- ✅ 整体视觉语言：Soft Blur Pastel Marketing / Soft Cream Teal Green；中文字体 Noto Sans SC；旅行者行囊（帆布 / 皮革暖冒险）Hub 隐喻。

## 2. 风格化还原技法手册

### 2.1 主色提取（从真币主导色 → 风格化签名色）

**核心规则（迁移锚点）**：**签名色 = 真钞主导色的粉彩化重演绎，不可偏离色相（hue）**。我们只把现实钞券的主导色相下沉（desaturate + 提亮）到 pastel 信封，使其既唤出真币记忆色、又明显区别于原票、且融入品牌调性；但**色相必须锚定真钞主色**——这是玩家在现实里认出该币的最强线索。所有取值与本策略给出的 hex 均为**风格化偏移结果，非原票复制**。

**四例复核（含迁移锚点）**：

| 币种 | 大洲形状 | 签名色 motif（粉彩化重演绎） | 辅助色 | 墨线 | 区域框色 | 真钞主导色（迁移锚点） | 复核结论 |
|------|---------|--------------------------|--------|------|---------|---------------------|---------|
| **USD** 美元 | 圆角矩形 | `#4E7A6B` 海绿（greenback 绿下沉） | `#EDE3CF` 羊皮纸 | `#3A3A38` | `#E0B15E` 金 | 现实美钞背面恒为绿（greenback） | ✅ 色相锚定正确，保留。USD 联邦储备券自 1929 起背面统一绿，海绿即最强迁移锚。 |
| **EUR** 欧元 | 六边形 | `#4A6E8A` 石板蓝（锚定 €20 蓝） | `#DCD3C4` 石灰白 | `#34404A` | `#5B8FB0` 蓝 | €20 = 蓝（最常被引用面额） | ✅ 色相锚定正确，保留。**但欧元按面额分色板**（€5 灰 / €10 红 / €20 蓝 / €50 橙 / €100 绿 / €200 黄褐 / €500 紫），签名色取最具代表性的 €20 蓝；生产时**可按面额延展色板**，见 §2.1 注。 |
| **JPY** 日元 | 菱形 | `#6E97A3` 青灰（锚定 ¥1000 空色蓝） | `#ECE3D2` 和纸米 | `#3A3A38` | `#87A878` 绿 | ¥1000 = 空色（sky blue，流通最广） | ✅ 色相锚定正确（蓝），保留。原描述「蓝灰」修正为锚定**现行 E 券 ¥1000 空色蓝**；日元同样按面额分色（¥1000 蓝 / ¥5000 紫 / ¥10000 褐），可按面额延展。 |
| **CNY** 人民币 | 菱形 | `#C75D4F` 暖绯红（锚定 ¥100 红票） | `#C9A24B` 金 | `#3A3A38` | `#87A878` 绿 | ¥100 = 红（俗称「红票」，最具代表性） | ✅ 色相锚定正确，保留。人民币多版有红/粉/绿/棕，取**最具代表性的 ¥100 红票**作主锚，暖绯红近陶土红族、落在 pastel 信封内。 |

> **演示「同区仍可分」**：CNY 与 JPY 同为「菱形 + 绿框」（亚洲·非洲），但 CNY 暖绯红 vs JPY 青灰——母题色层即在同形状内区分两币，证明四层模型的有效性；且两者色相分别锚定 ¥100 红、¥1000 蓝，迁移时不互相串色。

> **面额延展色板（EUR / JPY / CNY）**：欧元、日元、人民币的签名色可随面额延展为「同色相家族内的粉彩梯度」，既保留迁移锚点（色相不偏），又表达层级。延展规则：固定 hue，仅微调明度/饱和度 ±8%；面额差异仍以 §2.3 的「环数 + 尺寸 + 数字」为主通道，颜色延展仅作辅助提示，不替代可数信号。

**提取纪律清单（含迁移纪律）**：
1. **色相锚定真实主色**：签名色 hue 必须对应真钞主导色，不得为美观而偏移色相（最高优先级，迁移成败所在）。
2. 只取 1–2 个主导色相，不照搬票面全色谱。
3. 饱和度 ≤ 35%，明度 ≥ 55%（卡在 Soft Blur Pastel 内）；先锚色相、再下沉，顺序不可颠倒。
4. 与品牌三色（陶土红 / 青绿 / 金）保持 ΔE 间距，避免「撞色误读为同币」。
5. 落盘前人工比对：确认无任何原票可辨识的精确色值（粉彩化偏移 ≠ 复制）。

### 2.2 文化母题象征化（人像 / 建筑 / 动物 → 几何，不写实，但回声真钞中央母题）

真实钞币母题绝不写实复制，遵循「**选一 · 化简 · 扁平 · 纹样带**」四步。关键纪律：**象征母题必须对应真钞上真实存在的中央母题类别**（人像 / 建筑 / 动物 / 景观），让玩家在现实里见到该建筑、该动物、该肖像能触发记忆——这是迁移识别的第二根锚。

**技法表（保留原三式）**：

| 真实母题类别 | 风格化手法 | 几何表达 |
|------------|-----------|---------|
| **人像**（历史人物肖像） | 不画脸；改为「徽章圆章」 | 同心圆 + 放射状几何（月桂 / 星）+ 中央抽象字母形（取币种首字母的负空间） |
| **建筑**（窗桥 / 会堂 / 长城） | 轮廓剪影 → 几何 primitives | 半圆 + 梯形（拱券）；阶梯状 battlement（长城垛口）用 3–4 级矩形错位 |
| **动物 / 景观**（兽 / 鸟 / 山 / 花） | 负空间极简剪影 | 2–3 条 essential 曲线压成纯色块；置于圆形负空间窗内 |
| **纹饰 / 文字** | 文化纹样带（cultural pattern band） | 取自该文化「装饰语汇」的几何重复：希腊回纹 / 伊斯兰密铺 / 中国云雷纹 / 日本青海波——**暗示文化而不复制具体图案** |

**回声映射表（逐币种：真钞中央母题 → 我们的象征）**——生产时按此查证，确保母题类别不跑偏：

| 币种 | 真钞真实中央母题（正面 / 背面） | 我们的象征手法 | 现实触发记忆点 |
|------|------------------------------|--------------|--------------|
| **USD** | 正面：历史人物肖像（如华盛顿）｜背面：建筑 / 象征图腾 | 人像 → 徽章圆章（首字母负空间） | 玩家见真美钞人像，想起「圆章+字母」即 USD |
| **EUR** | 正面：「窗与桥」建筑（虚构但属建筑类）｜背面：同名建筑 | 建筑 → 拱券/桥几何剪影 | 玩家见欧钞桥/窗，想起「几何拱券」即 EUR |
| **JPY** | 正面：人物肖像（北里/野口等）｜背面：富士山 / 樱花 / 东京站 / 紫藤 | 人像 → 圆章；景观 → 富士三角 + 樱花点 | 玩家见日钞富士/樱花，想起「山形+花点」即 JPY |
| **CNY** | 正面：人物肖像（毛泽东）｜背面：人民大会堂 / 长城 / 西湖 / 桂林 / 长江 | 人像 → 圆章；建筑 → 会堂半圆 + 长城垛口 | 玩家见人民币建筑，想起「半圆会堂/垛口」即 CNY |

> 若某币种真钞中央母题是**动物**（如部分亚非货币用兽/鸟），则走「负空间极简剪影」一式，类别直接对应，迁移同样成立。

**化简原则**：每个母题 ≤ 4 个几何 primitive（圆 / 三角 / 弧 / 矩），单色平涂 + 1 道 accent 描边；**禁用真实雕版渐变 / 肖像灰度**。母题类别（人像|建筑|动物|景观）作为 §3.1 数据字段 `motif_category` 落库，供图鉴「现实辨认线索」回显。

### 2.3 面额（denomination）编码

面额层级**不靠颜色独占**，而靠「可数 + 可读」的三信号：

- **环数（pattern rings）**：Tier1（1/5/10）= 1 环；Tier2（20/50/100）= 2 环；Tier3（200/500/1000+）= 3 环。
- **尺寸（scale）**：高面额母题略大（≈ +8%）+ 外框微厚。
- **微光泽（sheen）**：Tier2 起加 1 道对角高光带（暗示 premium 印刷 / foil），但风格化为柔光，不复制全息。
- **数字 + ISO**（权威通道）：大字 Noto Sans SC 数字 + ISO 码，确保「看字即知」，绝不依赖美术猜面额。

### 2.4 材质与纹理暗示（纸感 / 金属感，不复制）

| 材质 | 暗示手法 | 生产备注（Cocos / 微信） |
|------|---------|----------------------|
| **纸币感** | 极低对比 grain 噪点（≤ 4% 不透明度）+ 柔内描边（仿毛边）+ 暖棉 tint | 共用 1 张 128px tiling 噪点贴图，sprite 叠加，**省 drawcall** |
| **硬币感**（未来硬币模式） | 同心弧径向拉丝 + 冷调微高光；形状改用**圆形**（仍带区域色环） | 同噪点贴图复用；避免运行时 shader，MVP 用烘焙贴图 |
| **微光泽** | 单道对角柔光带 sprite | 与面额 Tier 绑定，Tier1 不显示 |

> 噪点强度严控 ≤ 4%，避免微信小屏出现 moiré 与 pastel 被破坏。

### 2.5 形状语言（区域双编码与母题结合）

- **美洲 = 圆角矩形 + 金 `#E0B15E`**：圆角即「新大陆」暖、可亲的视觉暗示。
- **欧洲 = 六边形 + 蓝 `#5B8FB0`**：六边形 = 稳定 / 结构，呼应建筑母题。
- **亚洲·非洲 = 菱形 + 绿 `#87A878`**：菱形（45° 尖角方）= 异域 / 对称美学。
- **结合规则（双形态下）**：区域形状**不再是卡片整体外框**，而是卡面**角落小徽标**（标记「大洲」）——固定右上角（note）/ 上缘固定位（coin），见 §2.9.2；卡片整体外框由 `form_factor` 决定（coin=圆牌、note=横长方牌），区域色作徽标描边 + 边框带 accent；母题居中。玩家「看角标知大洲，看母题知币种，看形态知硬币/纸币」。

### 2.6 反合规红线自检（保证「不复制」）

每次资产产出过四关：
1. **无写实**：无人像五官、无可辨识真实建筑照片、无真实雕版。
2. **色偏移**：所有 hex 为风格化下沉值，与原票 ΔE 明显。
3. **几何化**：母题 ≤ 4 primitive，扁平单色。
4. **纹样原创**：cultural pattern band 取「语汇类型」而非具体国徽 / 行徽。

### 2.7 现实辨认线索（游戏 token ↔ 真钞的映射桥）【新增 · 含迁移识别修订】

**目的**：图鉴 / 详情页展示一行「现实锚」，把游戏内风格化 token 与现实钞券显式连接，强化迁移识别。这是漫画式保真闭环的最后一环——玩家在游戏里学到「圆章+海绿=USD」，在现实里见绿钞人像即可认出。

**数据字段（随资产落库，见 §3.1 #11）**：
- `real_dominant_color_name`：真钞主导色名（中文+原文），如「绿（greenback）」「红（红票）」「蓝（空色）」。
- `real_central_motif`：真钞中央母题类别 + 实例，如「人物肖像（华盛顿）」「建筑（窗桥）」「景观（富士山·樱花）」。
- `real_denomination_hint`：面额对照，如「常见 ¥1000 / ¥5000 / ¥10000」。

**文案规格（一行现实锚模板）**：
```
现实中的[币种]：[面额]主色为[现实色名]，中央母题为[真实母题]。
```
示例：
- 「现实中的美元：纸钞主色为绿（greenback），正面中央为历史人物肖像。」
- 「现实中的人民币：¥100 主色为红（红票），正面中央为人物肖像、背面为人民大会堂。」
- 「现实中的日元：¥1000 主色为蓝（空色），背面为富士山与樱花。」

**视觉规格（图鉴卡 / 详情页「现实锚」条）**：
- **位置**：卡面下方独立 strip，与游戏母题区分隔（用细分隔线 + 小标签「现实锚」）。
- **色样 chip**：放一枚**真实主导色相**的小色块（非粉彩化、用近似真色，如真绿 #2E5E3A、真红 #B22222、真空蓝 #4A78B0）——作为「真色回忆钩」，与游戏签名色并置可直观看出「同色相、不同明度」。
- **母题图标**：放一枚代表真实母题类别的线性 icon（人像剪影 / 建筑 / 山形 / 兽），呼应 §2.2 象征手法。
- **字号 / 对比**：锚文案用 Noto Sans SC ≥ 12sp，深墨 `#3A3A38` on 奶油白 ≥ WCAG AA；色样 chip 旁附色名文字，避免仅依赖颜色（色弱友好）。
- **可关闭**：教学期默认显示，老玩家可一键隐藏（设置项），不强制常驻以免干扰配对节奏。

### 2.8 漫画式保真 vs 过度抽象 纪律【新增 · 含迁移识别修订】

**目的**：给美术一条清晰红线——哪些是漫画式保真**允许且推荐**的抽象，哪些是迁移成败所系、**绝不可**抽象掉。防止美术走偏（过度抽象 → 玩家现实里认不出）或越界（写实复制 → 合规风险）。

**✅ 必须保留（迁移锚点，不可抽象掉）**：
| 锚点 | 为什么不可丢 | 落库字段 |
|------|------------|---------|
| **主导色相**（hue） | 玩家现实认钞最强线索；色相偏即串币 | `motif_color`（hue 锚真钞） |
| **母题类别**（人像/建筑/动物/景观） | 真钞中央母题类别是记忆触发点 | `motif_category` |
| **面额数字**（denomination 数字 + ISO） | 权威可读通道，看字即知 | `denomination_label` |
| **区域形状**（rect/hex/diamond） | 大洲编码，色弱兜底 | `region_shape` |

**🟡 允许且推荐的抽象（漫画式保真，弱化非关键细节）**：
| 可抽象项 | 处理方式 |
|---------|---------|
| 像素级纹理（真实钞纸纤维、雕版线纹） | → 共用 128px 噪点贴图（≤4%）暗示纸感 |
| 写实光影 / 立体（浮雕、全息、凹印凹凸） | → 扁平单色 + 至多 1 道柔光带，不复制全息 |
| 国徽 / 行徽精确造型 | → cultural pattern band（取装饰语汇类型，非具体国徽） |
| 肖像五官（真实人脸） | → 徽章圆章 + 币种首字母负空间 |

**🚫 过度抽象 = 迁移失败（红线）**：
- 同时丢失「主导色相」与「母题类别」→ token 与现实钞券完全脱钩，玩家认不出。
- 为统一品牌调性而把多币压成同一粉彩色相 → 串币，破坏四层模型。
- 用「抽象符号」替代真实母题类别（如把建筑母题画成无差别几何点）→ 记忆无法触发。

> 自检口诀：**「色相在、母题类在、数字在、形状在」= 保真；四项丢其二 = 过度抽象，打回重写。**

### 2.9 令牌形态（Token Form Factor）【新增 · 对齐 GDD §0.2 第 5 视觉轴 / §0.5 `form_factor`】

**目的**：引入 `coin` / `note` 双物理形态（GDD §0.5 `form_factor ∈ {coin, note}`），作为卡片**整体外轮廓**，直接服务「迁移识别」北极星——圆牌=硬币、长方牌=纸币。本节定义令牌**整体形态**怎么画；区域双编码形状（圆角矩形 / 六边形 / 菱形）在双形态下退居卡面**角落小徽标**（标记「大洲」），两者须严格区分（见 §2.9.2）。四层识别码（① 形状角标 ② 母题色 ③ ISO ④ 面额）保持不变。

#### 2.9.1 两种令牌怎么画

**coin 令牌（硬币形态）**
- **整体轮廓**：圆形或圆角方（圆牌），呼应真实硬币；轮廓内带 `region_color` 区域色环（沿用 §2.5 区域色）。
- **中心**：母题色 `motif_color` 占中心圆盘 / 主色块；中央母题几何（§2.2）居中。
- **文字**：ISO 码 + 面额数字置于盘面——可环绕中心盘下方或盘内下半部，深墨 `#3A3A38` on 奶油，≥ WCAG AA（§4）。
- **区域徽标**：置于令牌**上缘固定位**（如 12 点钟方向盘缘小徽标），不在盘面中央（见 §2.9.2）。
- **面额三信号**：环数 / 尺寸 / 微光泽（§2.3）在圆形内同样成立；Tier 以中心盘微厚 + 1–3 道环表达。

**note 令牌（纸币形态）**
- **整体轮廓**：横向长方形，**比例 `≈ 2:1`**，呼应真实纸币版式；**强制横屏 landscape**（GDD `NOTE_ORIENTATION = landscape`）。
- **中部**：横向 `motif_color` **母题色带**贯穿卡面中部；中央母题几何置于色带内。
- **文字**：ISO 码 + 面额数字**横排于色带旁或下方**，深墨 on 色带/奶油，≥ AA。
- **区域徽标**：固定置于**右上角**（见 §2.9.2），直径 ≈ 卡片短边 18%，与卡片外框明显区分。
- **材质**：沿用 §2.4 纸感（≤4% 噪点 + 柔内描边）；note 长方牌是**版式形状**，不含真实钞券图样 / 防伪元素（合规见 §2.9.3）。

#### 2.9.2 区域徽标位置 + 尺寸规则（与卡片外框严格区分）

区域双编码形状层（① 形状层）在双形态下退居**角落小徽标**，负责标记「大洲」，绝不与卡片整体形态混淆。

**通用规则（两种形态通用）**：
1. **固定位置**：coin = 令牌上缘固定位（12 点钟方向小徽标，固定不随内容漂移）；note = **右上角**固定位。位置恒定，玩家可形成「角标=洲」肌肉记忆。
2. **尺寸**：徽标直径 ≈ 卡片**短边 18%**（coin 短边=512；note 短边=512 → ≈92px @2x）。明确为「小标」，不占主导。
3. **带描边 + 中性填充**：徽标用 `region_color` 描边（2px @2x）+ 奶油/中性填充，**不与卡片填充同色同形**，确保轮廓可分离。
4. **单形不跨边**：徽标为独立小 chip，不贴满或跨越卡片任意整条边，避免被读作「卡片形状」。

**特别警示（`amer` 圆角矩形徽标）**：`amer` 的 `region_shape = rounded_rect`。在 note 长方牌上，它**只是右上角一枚圆角矩形小标**，**绝对不等于卡片整体形状**（卡片是 2:1 横长方牌）。即便 amer 徽标与卡片都为「带圆角矩形」语汇，也须靠**尺寸（18% 短边）+ 描边 + 单一右上角固定位 + 中性填充**四重手段，使其一眼落定为「角标」而非「卡形」。coin 圆牌上同理：amer 圆角矩形徽标是盘缘小标，不是圆牌本身。

> 自检：遮住卡片整体轮廓，仅留角标——仍能读出大洲；遮住角标，仍能凭圆牌/长方牌读出「这是硬币/纸币」。两通道互不替代 = 区分成功。

#### 2.9.3 合规红线重申（双形态）

- ❌ **禁用真实钞币 / 硬币图像**：coin 圆牌、note 长方牌均为**抽象几何呼应**（圆=硬币气质、长方=纸币版式），**非复制**任何真实硬币/纸币图样。
- ❌ note 长方牌**仅为版式形状**，**不含真实钞券图样 / 防伪元素**（水印、安全线、全息、凹印）。母题为风格化几何（§2.2），货币信息仅走四层识别码（GDD §6.3 契约）。
- ✅ 双形态均只渲染四层识别码（① 形状角标 ② 母题色 ③ ISO ④ 面额），与 §1 红线一致；ISO 标识、区域双编码、MVP 无汇率等约束在两形态下不变。
- ✅ 物理形态属「抽象几何呼应」，合规自检仍过 §2.6 四关（无写实 / 色偏移 / 几何化 / 纹样原创）。

#### 2.9.4 note-mode 横屏 UI 安全区 / 适配提示（可选补充）

note-mode 强制 landscape，须规避移动端横屏特有风险：
- **刘海 / 挖孔**：横屏下前置摄像头多在长边中段；卡片网格与安全文字须避开左右长边中段的 `SafeArea`（左右内缩 ≥ 44px @2x），ISO 码/面额不被遮挡。
- **横屏手势冲突**：iOS / 部分安卓横持时底部返回手势、音量键在长边；可点区与系统手势区保持 ≥ 16px 间距，避免误触返回。
- **最小可点区域**：4×4 网格在横屏下卡片仍须 ≥ 44dp 可点（GDD R1 同口径）；note 2:1 宽牌在窄屏（如 SE 横持 667px 高）须评估是否缩放或允许横向滚动，保证每卡 ≥ 44×44dp。
- **旋转引导**：用户竖持进入 note-mode 时，先弹「请旋转至横屏」引导遮罩，锁定 landscape 后再渲染，避免竖屏挤窄宽牌。
- **文本方向**：横屏下 ISO + 面额横排自然适配；中心母题色带与角标位置在设备倒置横屏时须镜像保持右上角固定（不建议支持倒置，默认锁定单一 landscape 方向）。

### 3.1 单资产要素清单（12 项，缺一不可）

| 12 | `form_factor` | `coin` / `note` | 物理形态轴（第 5 视觉轴）；与 `iso_code` 共同构成解锁实体 `(iso_code, form_factor)`（GDD §0.5）；驱动令牌整体轮廓（§2.9.1）与资产命名（§3.2） |

### 3.2 生产规格（与引擎对齐）

- **画布（按 `form_factor` 分档）**：coin `512×512` @2x（圆形/圆角方）；note `1024×512` @2x（≈2:1 横长方牌）；导出各 256/512 与 512/1024 两档。均 RGBA 透明底。
- **格式**：PNG-24 RGBA（透明底母题）；两种形态均 **Atlas 共用 128px 噪点贴图**（§2.4 ≤4%）打包降 drawcall。
- **命名**：`cur_<ISO>_<denom>_<region>_<form>.png`（`form ∈ {coin, note}`）；例：`cur_USD_100_amer_coin.png`、`cur_CNY_100_asia_afr_note.png`、`cur_EUR_20_euro_note.png`。每个 `(iso_code, form_factor)` 对 = 1 个独立资产。
- **噪点 / 光泽**：走共享 sprite + 叠加节点，MVP **不做运行时 shader**（微信性能预算友好，待程基岩确认可再加）。
- **字体**：所有数字 / ISO 码用 Noto Sans SC，确保中文生态一致。

## 4. 可访问性提醒（色弱模式）

- **不靠颜色识别**：① 形状（rect/hex/diamond）+ ③ ISO 码 + ④ 面额环数/尺寸 三重冗余，色弱下仍 100% 可辨。
- **区域三色防混淆**：金 `#E0B15E`（亮）/ 蓝 `#5B8FB0`（中）/ 绿 `#87A878`（中）明度接近，部分 CVD 下易混 → **加轮廓字形**（每大洲一个单色 icon glyph 置于卡角）+ 形状兜底。
- **面额不靠色**：Tier 用环数 + 尺寸 + 数字表达，绝不用「换色」表层级。
- **文本对比**：ISO 码 / 数字深墨 `#3A3A38` on 奶油白 `#F8F5F0` ≥ WCAG AA（4.5:1）。
- **高对比模式**（可选）：给形状加深色描边 outline 开关。
- **建议分级**：MVP 达 **Standard**（形状 + ISO + 文本三重冗余、AA 对比）；后续可升 Comprehensive（高对比 outline + 字距调节）。
