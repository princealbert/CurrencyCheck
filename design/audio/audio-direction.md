# 1. 诊断：这款游戏的听觉风险在哪

一款以「货币」为题材的配对游戏，默认会滑向两个错误方向，必须在方向层面就堵死：

1. **赌场化陷阱（最高危）。** 「配对成功 → 金币叮当哗啦 → 中奖号角」是休闲游戏的肌肉记忆配方，也正是老虎机的标准音效语言。本项目定位文化教育、红线明令禁投资/交易措辞，**一旦用了金币瀑布音，视觉层守住的合规会被听觉层一秒击穿**——玩家的耳朵比眼睛更早认出「这是赌博机」。这条是本方向文档存在的首要理由。

2. **工具 App 化。** 与美术侧诊断同源：系统提示音（iOS 风格「叮」、Material 风格「嘟」）会把「旅行手账」变回「记账 App」。合成音、纯正弦 pip、电子蜂鸣全部不可用。

**结论**：听觉身份必须与美术侧的「暖纸 + 珐琅章 + 手账」严格同构——**木、纸、玻璃、微弱铃**，而非金属、电子、金币。

# 2. 情感基调：「一间午后的旧书房，桌上摊着周爷爷的册子」

不是环游世界的冒险配乐，不是儿童游戏的欢快循环，是**一个人安静地把散落的东西一件件放回原处**的声音。

- **不是**：赌场 / 答题闯关 / 金融行情终端（紧张、金属、报数）；
- **不是**：儿童早教 App（过亮、过快、卡通拟声）；
- **是**：「Monument Valley 的克制 × 旧书房的空气感 × 八音盒的手工温度」。

三条**贯穿全部音频**的意象（对应美术 §2.1 的三意象）：

| 意象 | 听觉表达 | 出现位置 |
|---|---|---|
| 手账纸 | 书页翻动、纸张摩擦、软起振无尾音 | 翻牌 / 视图切换 / 对白弹出 |
| 珐琅章 | 木质闷响 + 玻璃泛音上扬（「盖章」） | 解锁收藏 / 星级 / 章节完成 |
| 旅程印记 | 八音盒短句、手风琴柔和终止式 | 里程碑 / 一局完成 / 首次开册 |

## 2.1 三条听觉铁律（等价于美术的「135° 光照约定」）

美术侧靠一条「光源恒在左上 135°」把材质感钉死。音频侧同样需要一条不可协商的物理约定，否则素材来自不同外包时必然散架：

> **铁律 1 · 软起振**：所有音效的 attack ≥ 8ms、无金属瞬态尖峰。起振材质只允许木、纸、玻璃、软槌。禁止 click/tick 类硬起振。
>
> **铁律 2 · 上行奖励，下行不惩罚**：正反馈一律**音高上行**；负反馈（错配）一律**下行且幅度 ≤ 小三度**，并保持柔和音色。项目**无失败态**（GDD §1.④），因此错配音的设计目标是「提示」而非「否定」——听感上必须像轻轻摇头，不像答错蜂鸣。
>
> **铁律 3 · 暖纸高频衰减**：所有素材在 8kHz 以上做 −6dB 搁架衰减，2–4kHz 不得有突出峰值。这是「暖」的技术定义，也是儿童长时间佩戴耳机的听觉保护。

任何素材偏离这三条 = 退回外包重做，不进包。

# 3. 乐器 Palette

## 3.1 白名单（核心配器）

| 层 | 乐器 | 职责 |
|---|---|---|
| 主旋律 | 卡林巴（拇指琴）、八音盒 / 音乐盒 | 温度与手工感；短句、留白多 |
| 辅色 | 毛毡钢琴（felt piano）、颤音琴（vibraphone，软槌） | 和声垫底、奖励音尾光 |
| 旅行色 | 手风琴（弱奏、长音） | 「启程」意象；仅用于里程碑与章节完成 |
| 拨弦 | 尼龙弦吉他（指腹轻拨，无甲片） | Hub 与图鉴的低密度节奏感 |
| 底床 | 暖垫（warm pad，低通 ≤ 4kHz）、极轻室内空气声 | 空间感，音量始终 ≤ −30dB |
| Foley | 书页翻动、纸张摩擦、木片轻碰、瓷片、极小铃铛 | 全部交互音的物理材质来源 |

## 3.2 黑名单（禁用音色 · 合规与调性双重红线）

| 禁用 | 理由 |
|---|---|
| 金币碰撞 / 金币瀑布 / 钱袋哗啦 | **赌博联想**，直接击穿零投资红线 |
| 老虎机滚轮、中奖号角、鼓点 fanfare（brass） | 同上，博彩语言 |
| 收银机「叮——」、点钞机、扫码「嘀」 | **交易联想**，指向支付/清点货币 |
| 真实硬币 / 真实纸币采样 | 违反「禁用真实钞币」红线（美术红线的听觉对应物） |
| 电子蜂鸣、系统提示音、纯正弦 pip | 工具 App 化 |
| 铜管、supersaw、失真、Riser / Impact（预告片音效） | 与温情克制调性冲突 |
| 人声拟声（「哇」「耶」）、儿童欢呼采样 | 本地化风险 + 与册册「录制向导」设定冲突 |
| 心跳、倒计时滴答 | 项目**无计时无失败态**，制造焦虑属支柱漂移 |

## 3.3 区域音色：明确**不做**国别乐器 Cosplay（重要决策）

游戏含 `amer` / `euro` / `asia_afr` 三区域 + `world` 环球章。直觉方案是「美洲配班卓、欧洲配手风琴、亚非配打击乐」——**本方向明确否决**：

- 用一件乐器代表一整个大洲（尤其「亚洲·非洲」合并区）是**文化刻板印象**，对一款以文化教育为定位、给儿童玩的产品是实质性的品牌与舆论风险；
- 与美术侧策略也不一致：美术用**抽象几何 + 区域双编码色**做区分，不用国旗、不用真实图样。音频应同构。

**采用方案**：全局共用同一套 palette，区域差异只体现为**音色微染**（timbral tint），不换乐器：

| 区域 | 音色微染 | 实现手段 |
|---|---|---|
| amer（金） | 略暖、混响稍干 | 卡林巴主奏，reverb decay 1.2s |
| euro（蓝） | 略清亮、空间稍大 | 八音盒主奏，reverb decay 1.8s |
| asia_afr（绿） | 略柔、低频略厚 | 颤音琴主奏，reverb decay 1.5s |
| world（环球） | 三者叠化 | 卡林巴 + 八音盒同奏，reverb 1.5s |

> 落地成本说明：v1 **不为每区域单独出资产**。区域微染只作用于 BGM 的可选变体（见 §5.4，v2 项）；v1 所有 SFX 全区域共用，仅 `sfx_region_complete` 需要 3 个尾音变体（成本 3 个小文件）。

# 4. 情绪曲线（按视图）

现有视图状态机为 `hub | pair | codex | detail`（`src/app/app.ts:77`）。情绪曲线按这四态设计：

| 视图 | 玩家心理 | 音乐能量 | 密度 | 目标听感 |
|---|---|---|---|---|
| `hub`（行囊 / 收藏册封面） | 期待、回访、「今天看点什么」 | 中低（0.45） | 中：主题旋律可辨 | 摊开册子前的那口气 |
| `pair`（配对对局） | 专注、记忆、无压力 | **最低（0.30）** | 极低：几乎只有垫 + 稀疏点缀 | 背景必须让路给交互音 |
| `codex`（图鉴书架） | 欣赏、清点、成就感 | 中（0.40） | 中低：缓慢拨弦 | 安静博物馆的展厅 |
| `detail`（货币详情） | 阅读、了解、沉浸 | 低（0.35） | 最低 | 凑近看一件展品 |

**关键决策 —— 对局 BGM 必须比直觉更安静。** 配对玩法的核心反馈是翻牌与配对音效；BGM 若有明显旋律，会与 16 张卡的高频交互音打架，长局（T3 环球 18 对）尤其疲劳。`bgm_match` 的设计目标是「几分钟后玩家想不起它长什么样」。

**情绪高点**只有三个，全部由 SFX 而非 BGM 承担：新币首次解锁、一局完成 + 星评、章节完成。BGM 全程保持平稳，不做戏剧化推进——这与「轻松无限」支柱一致。

# 5. BGM 策略

## 5.1 分轨方案：3 轨（不是 4 轨）

| 轨 | 覆盖视图 | 建议 loop 长度 | 建议体积 |
|---|---|---|---|
| `bgm_hub` | `hub` | 60–75s | ≤ 900KB |
| `bgm_match` | `pair` | **90–120s** | ≤ 1.1MB |
| `bgm_codex` | `codex` **+** `detail` | 60–75s | ≤ 900KB |

**为什么 codex 与 detail 共用一轨**：两者是「书架 → 取下一本」的连续动作，玩家进出详情非常频繁（图鉴每点一个币就进出一次）。换轨会造成反复淡入淡出，比不换更吵。共用轨 + 进入 detail 时**不重启、仅将音量从 0.40 平滑压到 0.35**，听感是「凑近了一点」，而非「换了个场景」。省一轨也直接省 ~900KB。

**为什么 match 轨最长**：对局是唯一会连续停留 3–10 分钟的场景，60s loop 在这里会被听出接缝。90–120s 是「不显重复」与「体积可控」的平衡点。

## 5.2 Loop 与切换规范

- **无缝 loop**：所有 BGM 必须是采样级无缝循环（首尾同相位、无静音 padding）。交付时需附 loop 点验证（连播 3 圈无可闻接缝）。
  - ⚠ 工程注意：`InnerAudioContext.loop = true` 依赖解码器实现，mp3 因编码器 padding **可能产生毫秒级间隙**。若真机实测有缝，回退方案见 `audio-implementation.md`（尾部预留 + 手动 seek，或改用 WebAudio 调度）。这是本方向唯一一个需要真机验证后才能定稿的技术点。
- **切换**：交叉淡变 400ms（出 400ms / 入 400ms，重叠）。禁止硬切。
- **首启**：冷启动**不自动播 BGM**。等待首次用户交互后再淡入 800ms（Web 端浏览器自动播放策略强制要求；微信端也更礼貌）。
- **后台**：`onHide` 立即淡出 200ms 并暂停，`onShow` 淡入 400ms 续播（不重头）。

## 5.3 自适应分层（intensity layer）：v1 **不做**

结论：**v1 采用单轨 + 音量包络 + ducking，不做分层**。理由是工程事实而非偷懒：

- 微信 `wx.createInnerAudioContext()` **不提供采样级多轨同步**。用 2–3 个 InnerAudioContext 播分层 stem，在低端 Android 上必然产生几十毫秒漂移并逐渐累积，几分钟后分层会明显错位——这比没有分层更糟。
- 分层意味着每轨拆 2–3 个 stem，BGM 体积直接 ×2–3，与本项目已经爆表的包体预算正面冲突。
- 本游戏无战斗、无强度递增，情绪曲线本就平稳（§4），分层能表达的东西很有限。

**v2 可选路径**（若确有需求）：改用 `wx.createWebAudioContext()`（基础库 2.19.0+），它提供 `AudioBufferSourceNode.start(when)` 精确调度，可实现真正同步的分层与节拍对齐。届时需程基岩确认目标基础库版本下限。**存疑项，本文档不做承诺。**

## 5.4 章节音色变体：v2 项

按 §3.3，区域微染只影响 BGM。v1 全章节共用 `bgm_match`。若后续玩家反馈「四章听起来一样」，v2 再出 `bgm_match_amer/euro/asia_afr` 三个微染变体（同一作曲、换主奏音色与混响，约 +2MB CDN）。**不进 v1 范围。**

# 6. 混音说明（Mixing）

## 6.1 总线结构

InnerAudioContext 只有实例级 `volume`，没有真实总线。因此「总线」是 AudioManager 内的**逻辑增益链**，最终音量按下式计算：

```
finalVolume = muted ? 0
            : clamp01( categoryVolume × busGain × eventGain × duckFactor )
```

| 总线 | 默认增益 | 用户可调 | 说明 |
|---|---|---|---|
| `MASTER` | 1.00 | 静音总开关 | 一键静音 |
| `MUSIC` | 0.55 | ✅ 独立音量 | 所有 BGM |
| `SFX` | 0.85 | ✅ 独立音量 | 所有音效根 |
| `SFX.UI` | ×0.70 | — | 点按 / 返回 / 切换 / 滚动 |
| `SFX.GAMEPLAY` | ×1.00 | — | 翻牌 / 错配 / 配对 |
| `SFX.REWARD` | ×1.00 | — | 解锁 / 星级 / 章节 / 里程碑 |
| `SFX.NARRATIVE` | ×0.80 | — | 册册对白弹出音 |

UI 子组压低到 0.70 是有意的：点按音是全局出现频率最高的音，与奖励音等响会让整体听感嘈杂。

## 6.2 响度目标

| 类别 | Integrated LUFS | True Peak |
|---|---|---|
| BGM | −20 LUFS | ≤ −1.5 dBTP |
| SFX（单发） | −16 ～ −14 LUFS(short-term) | ≤ −1.0 dBTP |
| 奖励音叠加峰值 | — | 合计 ≤ −3 dBFS |

「奖励音叠加峰值」针对新币解锁时刻——该时刻最多有 3 个音重叠（配对成功 + 解锁盖章 + 对白弹出），必须在**素材阶段就留好头空**，不能指望运行时限幅（InnerAudioContext 无限幅器）。

## 6.3 Ducking（对白压低）

册册对白是本作叙事的唯一载体，必须听得清（即使它是纯文字 toast——ducking 的作用是**让玩家把注意力交给文字**）。

- 触发：toast 入队并开始 enter 动画时；
- 动作：`MUSIC` 总线 ×0.60，attack 180ms；
- 恢复：最后一条 toast 退出后，release 400ms 回到 1.00；
- **必须用引用计数**：toast 队列容量为 3（FIFO），连播多条时若按「每条各自恢复」会在中间闪回音量。计数归零才恢复。

细节实现见 `audio-implementation.md` §5。

## 6.4 混响与空间

无需运行时混响（InnerAudioContext 不支持效果器）。**所有混响烘焙进素材**。全局约定：

- SFX 干湿比 ≈ 85/15，decay ≤ 0.8s（交互音必须干净利落）；
- 奖励音可到 decay 1.2–1.5s（尾光是「珐琅章」质感的来源）；
- BGM 按 §3.3 区域微染的 decay 值。

# 7. 参考情绪关键词 + 外包 Brief 要点

## 7.1 五个情绪关键词（交付给作曲/音效外包的锚）

1. **暖纸微光**（Warm Paper Glow）—— 一切音色的底色；软起振、无锐利高频。
2. **旧书房的午后**（Study-Room Afternoon）—— 空间感：室内、有家具吸音、不空旷。
3. **手账翻页**（Journal Page-Turn）—— 所有交互音的物理原型。
4. **静谧博物馆**（Quiet Museum）—— 图鉴与详情的听感目标：安静但不死寂。
5. **启程前的行囊**（Packed Suitcase, Before Departure）—— Hub 的情绪：期待，尚未出发。

> 情绪参考（仅作**氛围**对齐，**严禁**旋律模仿或采样引用）：Monument Valley、Gorogoa、Old Man's Journey、Alto's Odyssey 一类的克制配器与低密度编排。

## 7.2 外包 Brief 要点（可直接粘给供应商）

**项目**：微信小游戏《货币图鉴》，货币主题记忆配对 + 文化图鉴。受众儿童 + 成人。

**必须遵守**：
1. 三条听觉铁律（§2.1）：软起振 ≥8ms / 上行奖励下行不惩罚 / 8kHz 以上 −6dB。
2. 乐器白名单（§3.1）内选材；黑名单（§3.2）**一票否决**——尤其**任何金币、老虎机、收银机、点钞机、中奖号角类音色，以及任何真实货币采样**。
3. 响度与头空标准（§6.2）。
4. 混响全部烘焙进素材（§6.4），不留运行时处理需求。
5. 交付 mp3（44.1kHz）；SFX 单声道，BGM 立体声。单文件体积上限见 `audio-implementation.md` §6。
6. BGM 必须无缝 loop，交付时附连播 3 圈的验证文件。
7. SFX 需按事件清单提供**变体数量**（见 `audio-events.md`），高频音（翻牌）至少 3 个变体。

**明确不要**：
- 不要「游戏化」——不要 fanfare、不要 riser、不要 impact、不要鼓组；
- 不要卡通拟声与人声；
- 不要为不同大洲写民族风格乐器（见 §3.3，这是硬要求，不是偏好）。

**交付物**：按 `audio-events.md` 事件清单逐条交付，命名严格遵循该文档的命名约定；附一份源工程（stem 可选）供后续调整。

# 8. 配音（VO）方向

## 8.1 v1 结论：**不做 VO**

册册（CECE）是本作唯一有台词的角色，但 v1 建议**不录制配音**，理由：

1. **叙事已完整闭环**：对白经 `dialogueEngine` 走 toast 文字通道（12 节点），文字本身就是设计好的交付形态；
2. **包体不可承受**：12 个节点、MISS 池 7 条、REPEAT 池 8 条，实际台词量 30+ 条，即使 64kbps 单声道也是 1.5–3MB，在已经爆表的包体下不现实；
3. **本地化成本**：一旦有 VO，未来多语言就是整轮重录（需与路远行确认本地化路线图后再评估）；
4. **合规**：真人配音朗读货币相关内容，语气若有偏差更易被解读为推荐/背书；文字更可控。

**替代方案**：用一枚统一的 `sfx_dialogue_pop`（书页 + 木质 pip）作为册册的「声音签名」——玩家会把这个音与「册册要说话了」建立联结，成本仅一个小文件。这是低成本高性价比的角色听觉标识。

## 8.2 若未来做 VO（方向预留）

- **声线设定**：温和的中年女声或中性长者声，语速偏慢，气声比例略高（「录制的陪伴声音」设定 → 可加极轻微的老磁带底噪与带宽限制，强化「这是一段录音」，同时呼应周爷爷的年代感）。
- **绝不**：播音腔、儿童节目夸张腔、任何促销语气。
- **录制规格**：48kHz/24bit 单声道干声，无混响无压缩，交付前不做响度归一（由我方统一处理）。
- **字幕**：现有 toast 文字天然即字幕，**必须保留**并与 VO 严格同步，不得因有了 VO 就隐藏文字（可访问性硬要求）。
- **本地化**：需与路远行对齐语言范围后再定；建议 VO 走 CDN 按语言包懒加载，绝不进主包。
