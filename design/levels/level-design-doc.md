# 货币图鉴 · 关卡设计文档（区域章节版）

> 角色：LevelDesigner（空间叙事 / 流程架构）
> 日期：2026-07-31
> 对象：`minigame/`（Canvas 2D 对对碰）+ 周爷爷旅行行囊叙事框架
> 目标：把"3 档难度"升级为"按周爷爷旅行足迹划分的主题关卡章节"，补上审计缺口 A（区域书架 = 真正的关卡维度）
> 配套产物：`src/data/chapters.ts`（关卡数据，引擎直接读）、`src/data/currencies.ts`（扩池至 18 币）、`src/render/glyph.ts`（10 新币符）、`src/core/types.ts`（GlyphKind 扩展）

## 1. Intent（意图与情感弧）

**Player Fantasy**：玩家翻开周爷爷留下的旅行行囊，循着他的足迹走访各大洲——每翻开一对钱币，就在"认出"一个真实国家的文化名片。不是"背 8 张脸"，而是"跟着一位老人去过世界"。

**Pacing Arc（全局）**：
```
入境引导 → 单区熟悉(美洲) → 跨区环游(欧洲/亚非) → 环球高潮(环球) → 收集闭环
  T1低张     T2中张            T2/T3 扩池              T3 关联模式      星评+护照
```

**对齐设计支柱**：愉悦发现（每章有新币种）/ 可亲学习（现实锚在学习时刻触发）/ 轻松无限（无失败、星评只加不罚）。

**必须被记住的一刻**：在「亚非」章第一次翻开韩元，册册轻声说——"这朵浪你见过：日本千元钞背面的《神奈川冲浪里》，其实整片东亚都在浪里。" 跨章节的母题呼应，是记忆锚点，也是护城河。

**新机制引入顺序（一关只教一件）**：
- 美洲 T1：教"翻牌→找相同 ISO"的核心循环 + 现实锚闪现
- 欧洲 T1：教"母题≠币种"（同 portrait 母题但不同币，靠 glyph 区分）
- 亚非 T1：教"区域形状只分洲、币符才分币"（色弱通道）
- 环球 T3：教"关联配对"（货币 ↔ 它的动物/景观，而非两张相同）

## 2. 关卡架构（Critical Path）

**核心模型**：关卡 = (章节 `chapter`, 难度档 `grade`) 组合。
- `chapter` 决定**币种池**（区域维度 / 内容维度）
- `grade` 决定**网格/对数/副本**（难度维度）

**4 个章节按周爷爷 itinerary 顺序解锁**：

```
[美洲之旅] ──T1完成──▶ [欧洲之旅] ──T1完成──▶ [亚非之旅] ──T1完成──▶ [环球之旅]
   T1/T2/T3                T1/T2/T3                T1/T2/T3            T1/T2/T3(T3 关联)
      │                       │                       │                      │
      └── 各章 T2 需本章 T1 ───┘                       └── 三章 T2 全完成 ──▶ 解锁环球
```

**解锁链（no-fail 保底，与现有 tierConfig 门禁同哲学）**：
- 美洲：常开
- 欧洲：美洲 T1 完成 ≥1 局
- 亚非：欧洲 T1 完成 ≥1 局
- 环球：任意 ≥2 个单区章 T2 完成（或单区 T2 累计 ≥3 局）
- 章内 grade：T1 常开；T2 需本章 T1 完成；环球 T3 需环球 T2 完成
- 环球 T1 常开（解锁环球即玩，全池 18 币取 3 对子集、标准 match 3 对、3×2 网格）——不再跳过 T1，给"初识环球"一个低负荷起手

**Flow Diagram（玩家单局内）**：
```
[章节书架] → [册册开场白+周爷爷纸条] → [T1引导局 / T2环游 / T3关联]
                                                    │
                              ┌─────────────────────┤
                          [探索]                [首次解锁→现实锚闪现]
                              │                       │
                          [配对进行] ◀── combo 累积 ──┘
                              │
                          [棋盘清空] → [星评结算] → [返回书架 / 下一章提示]
```

## 3. 章节规格（Per-Chapter Spec）

| ID | 名称 | 副标题(足迹) | 币种池 | 引入机制 | 场景主题 key | 网格跨度 |
|----|------|------------|--------|---------|------------|---------|
| `amer` | 美洲之旅 | 新大陆的羽毛与冰川 | 6 币 | 核心循环 + 现实锚 | `scene_amer`（暖金+雨林绿） | 3×2 → 4×3 → 6×4 |
| `euro` | 欧洲之旅 | 桥与窗，和不在任何地方的城 | 6 币 | 母题≠币种 | `scene_euro`（冷蓝+石纹） | 3×2 → 4×3 → 6×4 |
| `asia_afr` | 亚非之旅 | 圣山、圣人与犀牛 | 6 币 | 区域形状只分洲 | `scene_asia_afr`（竹绿+沙金） | 3×2 → 4×3 → 6×4 |
| `world` | 环球之旅 | 周爷爷没走完的路 | 18 币(全) | 关联配对(货币↔母题，T3 引入) | `scene_world`（星图+航迹） | 3×2(T1 三对) → 6×6(T2 全池 18 对 match) → 6×6(T3 关联) |

### 3.1 美洲之旅 — 环境叙事
- **册册开场白**："周爷爷的第一站是美洲。他说这里的钱都带着翅膀——鹦鹉、潜鸟、神鹰。我们先从最轻的两张开始。"
- **周爷爷纸条**（书架角标）："在里约的清晨，一只金刚鹦鹉落在他肩头，他愣了半天，说'这鸟比我阔'。"
- **场景**：暖金底色 + 雨林剪影；书架木质纹理（行囊内格）。
- **遭遇设计**：T1 仅 3 对（USD/BRL/CAD 子集），首翻必有 1 个"新发现"→ 现实锚闪现教学；T2 铺满 6 币；T3 双副本（同币 2 对）拉记忆负荷。

### 3.2 欧洲之旅 — 环境叙事
- **册册开场白**："欧洲的钱最'客气'——桥是画出来的，谁都不偏心。但英镑上有个画家，叫透纳，他说'光就是色彩'。"
- **周爷爷纸条**："他在阿姆斯特丹看了一晚上桥，回来在笔记本上画了三十座，没一座是真的。"
- **场景**：冷蓝 + 石拱纹理；呼应 EUR 的"虚构桥"。
- **遭遇设计**：教学点 = "母题都是 portrait，但币不同"（EUR 建筑 / GBP 人像 / CHF 景观，教玩家别被母题骗）。

### 3.3 亚非之旅 — 环境叙事
- **册册开场白**："亚洲和非洲共用一本册子。这里的钱背面有山、有圣人、有犀牛——区域形状都是菱形，但每币的角标 glyph 都不一样。"
- **周爷爷纸条**："他在奈良喂鹿，鹿比他熟路。他说'认路的不一定是人'。"
- **场景**：竹绿 + 沙金；呼应 asia_afr 菱形。
- **遭遇设计**：教学点 = 色弱通道（区域形状只分洲，glyph 才分币）；CNY(十字)/INR(花) 同区域同 portrait，靠 glyph 拆开。

### 3.4 环球之旅 — 环境叙事（高潮）
- **册册开场白**："周爷爷的护照最后一页是空的。他说'剩下的路，你自己走'。这一章，钱不再成对出现——你要认出'谁属于谁'。"
- **周爷爷纸条**："空页旁边他写：'地图是别人画的，路是自己走的'。"
- **场景**：深蓝星图 + 淡金航迹线；所有区域色在此交汇。
- **遭遇设计（T1/T2 标准）**：T1 从全池 18 币抽 3 对做标准 match（3×2），作用是"初识环球"——第一次看到跨区混排，但负荷极低；T2 铺满全池 18 对（6×6）标准 match，是纯记忆容量峰值。
- **遭遇设计（T3 关联模式）**：卡牌一半是"货币"，一半是"它的母题/动物/景观"（如 BRL ↔ 绿翅金刚鹦鹉）。判定键 = `(iso, element)`，非同 iso 直比。这是审计创意 A 的落地，也是全游戏最难、最"图鉴"的一关。

## 4. 难度 × 网格映射（Content-bound）

**关键约束**：网格必须由"对数"推导，不能全局固定。单区池只有 6 币，硬上 6×6(18对) 会空 12 格 → 不可读。**`gridForPairs(pairs, form)` 按对数选最近似方整的网格**，coin 竖屏 cols≥rows、note 横屏交换。

| 对数 P | 卡数 | coin 网格 | note 网格 |
|-------|------|----------|----------|
| 3 | 6 | 3×2 | 2×3 |
| 4 | 8 | 4×2 | 2×4 |
| 5 | 10 | 5×2 | 2×5 |
| 6 | 12 | 4×3 | 3×4 |
| 8 | 16 | 4×4 | 4×4 |
| 10 | 20 | 5×4 | 4×5 |
| 12 | 24 | 6×4 | 4×6 |
| 18 | 36 | 6×6 | 6×6 |

**各章各档对数（pairsFor）**：
- `grade 1 初识`：`min(3, N)`，N=池大小（单区 6→3；环球 18→3）
- `grade 2 环游`：`min(N, 18)`（单区 6→6；环球 18→18）
- `grade 3 环球`：单区 `min(2N,18)`→12（6×4 双副本）；环球因 6×6 已是上限，`min(N,18)`=18 但切关联模式（见 §3.4）

权重逻辑**复用 `tierConfig.planFor`**：grade1 用 `isUnlocked` 权重（未解锁×3，把发现感还给前几局）；grade3 单区用 `pips` 权重（越不熟越常出现，w=4−pips）。扩池后该逻辑天然成立，无需改 tierConfig。

## 5. Pacing Chart（单局内 · 以美洲 T2 为例）

| 时间 | 活动类型 | 张力 | 备注 |
|------|---------|------|------|
| 0:00 | 叙事引导 | 低 | 册册开场白+周爷爷纸条(2.5s 淡出) |
| 0:10 | 探索(前 2 翻) | 低 | 教"看 glyph 角标" |
| 0:30 | 首个新发现 | 中→高 | 现实锚闪现 + 解锁 burst（教学时刻） |
| 1:00 | 配对进行 | 中 | combo 累积，错配仅数字反馈(no-fail) |
| 2:30 | 收束 | 低 | 棋盘渐空（matched 卡缩放 0.92+降亮） |
| 3:00 | 结算 | 低 | 星评 1–3★（只加不罚）+ 本章进度 |

> 单局目标时长：T1 ≤90s，T2 ≤3min，T3 ≤5min（关联模式更长）。无计时惩罚，时长仅作节奏参考。

## 6. Encounter / Flow 设计（遭遇与流程）

记忆配对没有"敌人"，但"遭遇"= **发现时刻 + 教学时刻 + 记忆负荷峰值**。每章设计：

1. **Tutorial Beat（仅首玩）**：本章首次进入，册册用 1 句话点出本币教学点（见 §3 各章）。只在 `!isUnlocked(chapter)` 时触发，复玩不打断。
2. **Discovery Beat（每次首解锁）**：翻出某币首对 → 现实锚闪现（flashPrimary）+ 解锁 burst（已落地 `fx.ts`）。这是北极星闭环点，必须保留并强化。
3. **Load Peak（T3/关联）**：双副本 + 跨区混排制造记忆干扰，是"难"的来源（空间优先于数值，符合设计纪律）。

**Navigation Affordance Checklist（Hub 区域书架）**：
- [ ] 4 个区域书架在 Hub 可见，按 itinerary 顺序横向排列
- [ ] 未解锁章节置灰 + "先完成「美洲」一局"轻提示（复用现有 toast 通道）
- [ ] 每书架显示本章进度（x/6 币 或 星评）
- [ ] 进入书架后，难度档(T1/T2/T3)作为子按钮，主路径比可选路径更亮
- [ ] 环球章用星图 icon 区别于三单区章（视觉层级清晰）
- [ ] 章节内 critical path 在 3 秒内可读（册册开场白不挡网格）

## 7. 内容池要求（扩池至 18 币 · 每区 6）

| 区域 | 现有 | 新增(草稿·锚点待事实核查) | 母题分布 |
|------|------|------------------------|---------|
| amer | USD, BRL | **CAD, MXN, ARS, CLP** | portrait/animal/animal/landscape/landscape/animal |
| euro | EUR, GBP | **CHF, SEK, RUB, PLN** | architecture/portrait/landscape/animal/animal/architecture |
| asia_afr | CNY, JPY, INR, ZAR | **KRW, NGN** | portrait/landscape/portrait/animal/animal/landscape |

- **新币符(GlyphKind)**：chevron / hexagon / star / leaf / disc / spiral / mountain / sun / bolt / rhombus（10 个，纯几何，色弱可用）。
- **合规红线**：绝不引用真实钞币图/国旗/防伪语言；anchor 文案过禁用词 gate（R4 事实核查）；母题走 person/landscape/animal 优先于 flag。
- **签名色**：每区 6 色互不撞；均为粉彩化真钞主色（锚定色相），待美术方向校准。

## 8. 集成说明（hub.ts / app.ts 改动点）

`chapters.ts` 已导出 `chapterPlan(id, grade, form, ctx)` 返回 `{ plan, grid, pairs }`，可直接喂 `buildDeckPlan(plan, CURRENCIES, form)`。需改动：

1. **`hub.ts`**：三档位按钮 → 4 个区域书架（amer/euro/asia_afr/world），点书架进入该章难度档子菜单（或书架直接展开 T1/T2/T3）。复用 `drawButton` + `drawTierSub` 样式。
2. **`app.ts`**：
   - `startPair(form, tier)` → `startChapter(id: ChapterId, grade: 1|2|3, form: FormFactor)`。
   - `isTierOpen(tier)` → `isChapterOpen(id)` + 章内 `isGradeOpen(id, grade)`（门禁见 §2）。
   - `meta` 维度从 `(tier)` 扩为 `(chapter, grade)` 存最佳星（现有 `metaStore` 结构加一层 key 即可）。
3. **`matchLogic.ts`（仅关联模式）**：`evaluate` 支持注入 `matchKeyOf(card)`；环球 T3 传 `(iso, element)` 键。标准模式不变。`chapters.ts` 已提供 `associationPlan()` 纯函数钩子，matchLogic 接一个分支即可。
4. **`app.ts` 开场白**：进入章节时若 `!isUnlocked(chapter)`，播 `narrativeBeat` + `grandpaNote`（复用 `flashPrimary` 通道或新增 toast 类型）。

> 关联模式(match currency↔motif) 是环球 T3 的"签名难度"，建议作为 Phase 2 落地（标准章节 Phase 1 即可上线）。`chapters.ts` 数据已就绪，matchLogic 接一个分支即可。

## 9. Playtest 成功指标

- 100% 测试者能在 Hub 3 秒内找到"下一章"入口（可读性）
- 单区章 T2 完成率 ≥80%（难度可读、无空格焦虑）
- 环球 T3 关联模式：≥2 种成功配对策略被观察到（标准"背位置"之外，有人用"母题联想"）
- 现实锚闪现后，≥70% 玩家能复述该币一条文化事实（北极星闭环）
- 扩池后首玩满星率观察（T1 阈值 m≤2 是否过松）→ 回到 `starRating.ts` 调 TUNABLE 系数
- 色弱模式：置灰签名色后，CNY(十字)/INR(花) 仍 100% 可区分（glyph 通道生效）

*设计结论：地基（core 纯函数 / tierConfig 权重 / starRating / glyph 色弱）已优秀。本方案把"区域"从图鉴分组标签升级为**真正的关卡维度**，用"周爷爷足迹"串成 critical path，每章教一件新事、每章有环境叙事。扩池 18 币是前提依赖，已一并起草。做完这步，"货币图鉴"才真正从"贴钱标签的对对碰"变成"跟着一位老人去过世界"。*
