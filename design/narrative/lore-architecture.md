# 分层知识架构（Lore Architecture）

> 原则：lore 永远可选——关键路径不读任何收藏品也能理解游戏。分层奖励探索，不要求探索。

---

## Tier 1：表层（Surface · 所有玩家必得）
关键路径内容，不读任何收藏品也能理解游戏。
- 前提：你继承了周爷爷的行囊与未竟的册子，要把散落的钱币名片配回来。（Hub 首开 + 日常回访）
- 配对成功即解锁：每张名片的**主母题 + 一句文化冷知识**（即 `dialogue-nodes.md` 的 `discoveryLine`）。
- 区域书架的视觉双编码（美洲金 / 欧洲蓝 / 亚非绿）作为世界视觉地标。
- 汇率快照条的"仅供参考，非金融建议"口径。

## Tier 2：进阶层（Engaged · 探索者）
会翻图鉴、读纸条、走区域上下文的玩家可得。
- **周爷爷的纸条**（`grandpaNote`）：每个币种一条，夹在图鉴页里，比 `discoveryLine` 更私人、更带老人视角。
- 各币**历史版本差异**：日元 E 券(富士+樱花) → F 券(神奈川冲浪里)；英镑 亚当·斯密版 → 透纳版；欧元前 legacy 货币(马克/法郎/里拉)被取代；人民币 1999→2005→2015 防伪迭代。
- "为什么绿色成了美元背面恒的主调"（greenback 源自 1861 南北战争）。

## Tier 3：深渊层（Deep · 考据党）
读遍所有内容、爱连点的人可得；多为**跨币种的元观察**。
- **母题选择的政治学**：USD/GBP/CNY/INR 选"人像"（建国者/艺术家/领袖），BRL/ZAR 选"动物"（生物多样性/野性），EUR 刻意选"虚构建筑"（政治中立），JPY 选"景观/名画"（自然与美学）。一张名片，是一个国家"想被怎么记住"的自我介绍。
- **语言即多样性**：南非兰特印了全部 11 种官方语言；印度卢比票面有 15+ 种语言面板——货币是"把多民族装进一张纸"的微型工程。
- **"real / rand"词源**：巴西 real = 皇家/真实；南非 rand 得名于 Witwatersrand（白水脊）金矿区——两个前殖民地用"真实/财富之脊"命名货币，是殖民与资源史的隐线。
- **greenback 与 polymer**：美元恒绿、英镑转聚合物寿命×2.5——防伪史是"信任如何被印刷"的技术史。

> 这些 Tier 3 绝不进关键路径，也不进任何强制弹窗；只在图鉴"深读"或未来"考据小栏目"出现。

## 世界圣经速查（World Bible Quick Reference）
- **Timeline（游戏内虚构）**：周爷爷的几十年旅程（模糊处理，不写具体年份，免与真实币种年份冲突）；真实币种系列年（USD 2013 / BRL 2012 / EUR 2015 / GBP 2020 / CNY 2015 / JPY 2024 / INR 2018 / ZAR 2012）作为"现实锚"仅用于教育事实，不进主线剧情。
- **Factions**：无阵营。区域（amer / euro / asia_afr）是收藏册的"书架"，不是势力。
- **Rules of the World**：① 游戏内令牌一律风格化几何母题，绝无真实钞币/硬币图；② 教育/文化框架，禁用金融建议；③ ISO 4217 代码呈现，不依赖国旗；④ 汇率=静态快照+免责。
- **Banned Retcons（永不可改的 Tier 1 事实）**：
  - USD 正面为富兰克林（非总统）；背面独立厅。
  - JPY 背面为《神奈川冲浪里》（最新 F 券）；富士山为日本圣山。
  - BRL 背面为绿翅金刚鹦鹉；正面共和国女神。
  - ZAR 正面曼德拉；背面白犀牛（五大兽）。
  - EUR 桥/窗为虚构建筑（政治中立）；12 星象征和谐。
  - GBP 透纳（光之画家）；名言"Light is therefore colour"。
  - CNY 背面人民大会堂；"人民币=人民的货币"。
  - INR 正面甘地；反面 Rani ki Vav 阶梯井。
  - **全局红线**：永不呈现真实钞币/硬币图像。
