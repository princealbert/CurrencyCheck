## §0 先读：触发条件是 **18 币种 / 36 实体**，不是 19

任务书写的是「集满 19 币种」。实测 `minigame/src/data/currencies.ts` 为 **18 币种**（`amer:6 / euro:6 / asia_afr:6`），与文件内注释"新增 10 币使每区达 6 币"自洽。

```
全收集 = 18 币种 × 2 形态（coin + note）= 36 个解锁实体
collectionStore.progress() ⇒ { unlocked: 36, total: 36, pct: 100 }
```

> ⛔ **若把触发条件写成 19 或 38，奖励层将永远不会触发。**
> ⚠️ **命名撞车警告**：`metaStore.ts` 里已有一个 `TOTAL_STARS = 36`（星星总数），与本处的「36 个实体」**是两个完全不同的 36**。请勿复用该常量做全收集判定，否则将来任一侧调整就会静默串号。

## §1 概念（Concept）

### 1.1 一句话

> 周爷爷生前在册子最后一页写下的一个约定：**把这些钱币都认全的人，值得亲眼去看看它们来的地方。** 册子填满的那一刻，这趟旅程被兑现——不是奖品，是一位老旅人早就替你准备好的**心意**。

### 1.2 它在叙事里的位置

| 维度 | 定位 |
|---|---|
| 触发层级 | **全收集**（整本图鉴集满）——全程仅此一次，**不是**每章通关 |
| 叙事功能 | 收束主线：玩家继承的是"未竟的册子"，册子完成 = 承诺兑现 = 周爷爷这条线的落幕 |
| 情感目标 | 温润、传承、文化好奇。是"被一位老人惦记着"的感觉，**不是**赢了什么 |
| 讲述者 | 周爷爷**本人视角**的字幕（不是册册转述）。全片是他留下的话，第一次直接对玩家说 |
| 时长 | ≈ 33 秒（可跳过） |

### 1.3 为什么讲述者要从册册换成周爷爷

全程 18 币的 `discoveryLine` / `grandpaNote`，玩家听到的都是**册册转述**（"他说……"）。册子集满这一刻，转述层撤掉、周爷爷直接开口——这是全游戏唯一一次视角切换，**切换本身就是奖励**。

> ✅ 合规守线：这是**周爷爷生前录制/写下**的内容，跟册册（生前录制的陪伴声音）同一设定，**不是灵异、不是显灵**。片尾落款必须明确写"写在册子最后一页"，把"预先留下"这件事讲死。

### 1.4 调性红线（player-facing 文案禁用词）

> **禁用**：奖励 / 奖品 / 奖金 / 大奖 / 抽奖 / 领取 / 恭喜中 / 稀有 / 价值 / 升值 / 收益 / 解锁大礼
> **改用**：礼物 / 心意 / 一趟远路 / 周爷爷留下的
>
> 内部代码标识符用 `worldTour` 无妨；**只要出现在屏幕上的中文，一律走上面右侧的词表。**

## §2 结算页布局（Layout）

### 2.1 图层顺序（自底向上，z 递增）

| z | 图层 | 内容 | 说明 |
|---|---|---|---|
| **L0** | 底色 | 纯色 `#1A1614` 暖黑，全屏铺满 | **必须有**。图片未加载完时若露出画布默认白底，会在暗色氛围里炸出一帧白闪 |
| **L1** | 名胜图 | 风格化名胜插画，Canvas 推镜（Ken Burns）+ 交叉淡入淡出 | 双缓冲：`current` 与 `next` 同帧绘制，靠 `globalAlpha` 交叉 |
| **L2** | 统一调色叠层 | 该帧所属区域的签名色，`globalAlpha ≈ 0.12` | **产线关键**：8 张图若来自 Seedream + 现成素材混合，色温必然不齐。这一层把它们强行拉回同一美术调性，比要求美术反复返工便宜得多 |
| **L3** | 暗角 / 晕影 | ① 径向渐变四角压暗 ② 底部 40% 高度线性压暗至 `rgba(0,0,0,0.55)` | ②是**字幕可读性的唯一保障**——不能依赖图本身够暗 |
| **L4** | 字幕 | 周爷爷视角文化注脚，1 行（窄屏可折 2 行） | 底部安全区上方 |
| **L5** | 标题「周爷爷的礼物」 | 顶部居中 | **仅前 3 秒显示后淡出**。长期挂在顶上会一直遮住名胜图的天空区，且削弱沉浸 |
| **L6** | 控件 | 进度点（8 个小圆点，当前帧实心）+ 跳过 / 关闭按钮 | 常驻，不淡出 |

### 2.3 时间轴（总计 ≈ 33s）

| 段 | 时长 | 内容 |
|---|---|---|
| 开场 | 2.0s | 黑场渐亮 + **主文案**居中淡入淡出（此段无名胜图） |
| 帧 1–8 | 每帧 3.4s（含 0.7s 与下一帧交叉淡化） | 名胜图 + 字幕 |
| 收束 | 3.5s | 画面渐暗至 `#1A1614`，落款文案 + 落款署名淡入 |
| 结束 | — | 淡出 → 返回 Hub（**不是**返回对局） |

**推镜参数**：每帧 `scale 1.00 → 1.06` 线性；平移方向按 `帧序 % 4` 轮换（左→右 / 右→左 / 上→下 / 下→上），避免 8 帧同向导致的机械感。
**字幕节奏**：字幕在该帧起始 +0.4s 淡入、结束 -0.5s 淡出，**不与图的交叉淡化同步**——错开能明显减轻"幻灯片感"。

### 2.4 可访问性与体感

- **跳过按钮从第 0 秒起常驻**，不做"3 秒后才能跳过"（那是广告的做法，会毁掉礼物的调性）。
- 字幕字号 ≥ 16px；**全部信息由字幕承载**，静音状态下体验完整（微信小游戏静音启动是常态）。
- 若 `settings.ts` 已有减弱动效开关：开启时**关闭推镜**，仅保留淡入淡出，帧时长不变。
- 单击画面任意处 = 暂停/继续（长文化注脚需要停下来读的空间）。

## §3 触发点与接线清单（给 engineering-lead）

### 3.1 核心设计决策：**延迟到局末，不在翻牌当场弹**

第 36 个实体解锁发生在 `flipCard()` 的 `firstTime` 分支里，**此刻棋盘上通常还有未配对的牌**。在那一瞬间弹出 33 秒全屏影片会：① 打断进行中的对局 ② 抢在星级结算之前 ③ 让玩家搞不清自己到底是赢了还是没赢。

**正确顺序：**

```
第36个实体解锁 → 只置 pendingWorldTour = true（不弹）
        ↓
对局自然结束 → finishWin() → 星星逐颗弹出 + sfx_win_session（现有体验不动）
        ↓
玩家点「继续 / 返回」→ 检查 pendingWorldTour
        ↓
     true → 进入 world_tour（而不是回 Hub）
        ↓
影片播完 / 跳过 → 标记已看 → 回 Hub
```

### 3.2 逐文件接线清单

| # | 文件 | 改动 | 说明 |

### 3.3 ⚠️ 三个容易踩的坑

**坑 1 — 音乐会自动跟着 view 走。**
`app.ts` L355 是 `const scene: MusicScene = this.view;`。这意味着**一旦把 `'world_tour'` 加进 `View`，音乐系统会立刻拿它去查 `SCENE_MUSIC`**。若忘了加映射项，运行时会取到 `undefined` → 静音或抛错。第 11 项与第 6 项**必须同一个 commit**。

**坑 2 — 动画驱动。**
本层需要**每帧连续重绘**（推镜是逐帧的）。现有代码大量使用 `this.dirty = true` 的脏标记模式。请确认驱动方式：若是脏标记按需渲染，则 `world_tour` 激活期间需**每 tick 强制置 `dirty`**（可参照 `won` 状态下星星弹出动画的现有做法）。**这条请 engineering-lead 回确认一次**，我无法从静态阅读断定。

**坑 3 — 图片没到就开播。**
8 张图走 CDN，弱网下必然有帧未就绪。**要求**：`openWorldTour()` 前至少预载前 2 帧；播放中某帧未就绪时**不卡住**，用 L0 底色 + L2 该区域签名色渐变兜底，字幕照常走（字幕承载全部信息，见 §2.4）。**绝不能出现转圈等待**——那会把"礼物"变成"加载"。

### 3.4 重看入口（强烈建议保留）

一次性播放的 33 秒内容，玩家很可能在通勤路上被打断、或手滑跳过。做成永久不可回看，等于把整个投入变成一次性消耗。

**建议**：Hub 或图鉴页顶部，全收集达成后常驻一枚小图标（行囊 / 明信片），点击 `openWorldTour(replay = true)`。重看时**跳过开场 2s 主文案**（已看过，直入名胜），其余不变。

### 4.1 结算主文案（开场，2s）

**主选：**
> 「把这些钱币都认全的孩子，
> 　该去看看它们来的地方了。」

**备选 A（更直接）：**
> 「你把它们都认回来了。
> 　现在，换我带你走一趟。」

**备选 B（更克制）：**
> 「册子满了。
> 　那我们说好的那趟远路，也该动身了。」

> 三选一由主理人拍板。三条均已过禁用词表（§1.4）。

### 4.2 收束落款（片尾，3.5s）

> 「册子合上了，路还长。剩下的，你自己去看。」
>
> 　　　　　　　　　　—— 周爷爷，写在册子最后一页

### 4.5 ⚠️ 中国台湾·太鲁阁 —— 建议**暂不纳入**，需主理人拍板

任务书把「中国台湾·太鲁阁」列为候选。我的判断：

- **表述本身没问题**：写作「中国台湾·太鲁阁」符合铁律。
- **但结构有风险**：本清单其余各项均为「国家·地标」格式并列。若在这样一个并列序列中插入一项，**列表结构本身**会隐含并列主体的对等性——这是排版层面的问题，不是字面表述能解决的。

**如果主理人决定纳入，必须同时满足：**
1. 与「中国·长城」**相邻编排**，且合并为**同一个中国分组**（如一帧内双景，或标注为「中国 · 长城 / 中国台湾 · 太鲁阁」的连续两帧并共用一个分组标签）；
2. **绝不**以独立并列项出现在与「日本」「瑞士」平级的序列位置；
3. 上线前过一轮合规复核。

**我的建议：本期先不加。** 8 帧核心已覆盖三大区域且每帧有币种出处，收益有限而结构风险实存。

### 4.6 字幕与暗线的收束

文档 A（`codex-copy-completion.md` §4）记录了一条跨币种暗线：**海 → 远方 → 某个"大家伙"**。

- KRW 纸条埋下："像有个大家伙，正在远处慢慢地游。"
- ARS 纸条兑现："那个大家伙终于浮上来时，海先安静了一下。"
- **本影片第 8 帧完成最终收束**：字幕「等了一整天它才浮上来，那一下，海先安静了。」——玩家在这一帧才第一次**看见**那个大家伙。

同时，第 1 帧（浪）、第 5 帧（云，呼应 CHF 纸条）、第 7 帧（望着远方，呼应 CLP 纸条）都是纸条原句的视觉回响。**读过纸条的玩家会认出来；没读过的也不损失理解**——完全符合 lore 分层"奖励探索，不要求探索"的原则。
