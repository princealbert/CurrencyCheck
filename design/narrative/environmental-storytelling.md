# 环境叙事 Brief（Environmental Storytelling）

> 用途：把叙事"写进空间与道具"，让美术/林绘澄在落地 Hub 时有故事依据，而非只摆 UI。

---

## Environmental Story Beat: 旅行者行囊 · 内部（中央 Hub / S1）

**What Happened Here**：
这是周爷爷留下的旧行囊。他走遍世界后，把一路收集的钱币名片夹进这本《钱币收藏册》，并在书页里塞了纸条、旧票根、甚至咖啡渍。如今他不在了，册子半空、名片散落。你作为"有缘分的年轻人"接过了它——行囊的"内部"就是你的基地：一本摊开的册子，周围几排区域书架。

**What the Player Should Infer**：
- 这不是菜单，是一个**有人住过、有人爱过的空间** → 自然产生"把它填满"的动机，而非被 UI 催促。
- 散落的名片 = 待拼回的世界；区域书架 = 周爷爷整理世界的秩序感。

**What Remains to Be Mysterious**：
- 周爷爷到底去了哪里？（不答，留白给孩子想象——也许是"又出发了"，也许是"把路交给你了"）
- 那本空着的旅行护照，最终会通向哪？

**Props and Placement**：
- 摊开的《钱币收藏册》（画面中央）：书页有大片空白格 → 暗示"等你来填"。
- 区域书架三排（左/中/右，双编码）：美洲金圆角矩形 / 欧洲蓝六边形 / 亚非绿菱形 → 既是导航也是世界观地标。
- 一杯干掉的咖啡渍印在扉页（道具）：说明主人常在这里一坐半天 → 温度感。
- 夹着的旧票根 / 泛黄纸条（可点）：点开即 Tier 2 周爷爷纸条。
- 册子最后一页的**空护照槽**（半透明剪影）：teaser，不强制。

**Lighting Story**：暖色、像书房台灯下的光——安全、专注、欢迎，而非冷蓝的"App"感。

**Sound Story**：翻书声、远处极轻的旅行环境音（海浪/风铃，按区域切换）→ 让"世界"有呼吸；无警报、无倒计时。

**Tier**：[x] Surface（空间本身） [x] Engaged（可点纸条）

## Environmental Story Beat: 空着的旅行护照槽（teaser / S5 预留）

**What Happened Here**：周爷爷在册子末页留了个空位，说"等册子填得差不多，就给你开"。

**What the Player Should Infer**：世界里还有"下一程"在等你，但此刻不在 MVP 范围——降低对未实现功能的焦虑。

**What Remains to Be Mysterious**：护照开了之后会去哪？（未来拓展钩子）

**Props and Placement**：册子最后一页，一个半透明、带虚线边框的小本子剪影；轻点触发 `PASSPORT_TEASER` 对白。

**Lighting Story**：比主册略暗，像"暂时合上的那页"。

**Sound Story**：轻"叮"一声，像有什么在等你。

**Tier**：[x] Surface（可见）

## 环境叙事自检（给评审）
- [ ] 70%+ 玩家无需文字提示即可推断"这是有人住过的行囊、要把名片配回来"？
- [ ] 咖啡渍 / 纸条等道具不喧宾夺主，不挤占配对视线？
- [ ] 空护照槽明确是"未解锁"，不造成"功能坏了"的误读？
