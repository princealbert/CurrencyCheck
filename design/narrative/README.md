## 1. 叙事框架（Narrative Framework）

### 1.1 核心主题问题（Central Thematic Question）
**"一张小小的钱币名片，能装下一个地方多少故事？"**
游戏不回答"钱值多少"，而是引导玩家发现：每个地方的货币，都是当地人选择"把自己介绍给世界"的方式。

### 1.2 情感弧线（Emotional Arc）
- **起点**：你接到一只旧行囊，对里面的世界一无所知，有点茫然。
- **中段**：你在配对与翻阅中，逐渐看见八大文化切片——从富兰克林到神奈川冲浪里，从金刚鹦鹉到曼德拉。
- **终点**：你不再是"在玩配对游戏的人"，而是"一个开始用文化眼光看世界的人"。行囊被你填满了，但好奇心是它真正想交给你的东西。

### 1.3 叙事支柱 ↔ 游戏设计支柱对齐
游戏设计三支柱（来自 IA 提案）：①愉悦发现 ②可亲文化学习 ③轻松无限。

| 游戏设计支柱 | 叙事对应支柱 | 如何互相强化 |
|------|------|------|
| 愉悦发现 | "拼回散落的世界" | 配对=发现，发现=故事解锁，juicy 反馈即叙事节拍 |
| 可亲文化学习 | "钱币是文化窗口" | 每张名片背后一段人话讲解，无说教 |
| 轻松无限 | "周爷爷的旅程没有终点" | 无失败、无体力、无压力；册册永远温和 |

### 1.4 合规边界（置顶，全文适用）
- 游戏 ship 的是**风格化几何母题令牌**，绝非真实钞币/硬币；叙事与美术同守此线。
- 定位**教育/文化**，定位不漂移；**禁用投资 / 交易 / 预测 / 抄底类措辞**。
- 汇率仅为**每日静态快照**，对话与 UI 出现时必带"仅供参考，非金融建议"口径。
- 货币以 **ISO 4217 代码**呈现，不依赖国旗。

## 2. 前提与世界观（Premise & World）

**设定一句话**：你继承了一只旅行者行囊，里面是一本还没填满的《钱币收藏册》，和一位住在书里的语音向导——**册册**。册册是行囊原主人**周爷爷**（一位退休地理老师、走遍世界的老旅人）生前录进书里的陪伴声音。行囊里原本装满了他带回的"钱币名片"（各国文化的风格化令牌），年深日久散成了单张。你的任务，是把它们一双一双，配回来。

- **钱币名片**：游戏内对货币令牌的称呼——明确是"文化名片"，不是"钱"。玩家配对的是名片，解锁的是故事。
- **区域书架**：Hub 内以双编码组织（美洲=圆角矩形+金 / 欧洲=六边形+蓝 / 亚非=菱形+绿），是收藏册的"书架"，不是 tab。
- **旅行护照**：册子最后一页预留的空位，未来拓展；当前为 teaser。

## 3. 叙事交付模型（重要：本游戏不用对话分支树）

本游戏是**沉默主角 + 状态驱动**的休闲收集游戏，玩家没有"对话选项"这种机械选择。因此叙事**不采用分支对话树**，而采用**系统叙事 / 状态触发**：册册的对白根据玩家状态（已发现哪些币、区域完成度、连续天数、是否首次）被系统选出。这正符合"故事中的玩家能动性 = 玩法中的玩家能动性"原则——玩家的"选择"是**收集什么、看什么、回访与否**，而非菜单选项。

> 对应专家能力里的"Emergent & Systemic Narrative"：用游戏状态 flag 驱动册册台词，玩家不会察觉接缝。

## 4. 角色名册（详见 character-voice-pillars.md）
- **册册（CECE）**：行囊收藏册的语音向导，周爷爷的录音风格。唯一常驻说话角色。
- **你（玩家）**：沉默主角，被册册称为"你 / 小旅人"。无姓名、无台词。
- **周爷爷（隐含角色）**：已不直接出场，通过册册的回忆与夹在册子里的纸条（Tier 2 内容）呈现。
