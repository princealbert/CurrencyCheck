# 货币图鉴 · 竞争分析与差异化定位（2026-07-26 补充研究）

> 文档类型：市场 / 竞争分析 + 定位建议  
> 作者：主理人（游承峰）汇总，基于用户初稿调研 + 联网复核  
> 范围：微信小游戏「全球钱币收藏配对」赛道的竞品盘点与差异化定位  
> 依赖：用户输入调研稿、`design/menu-ia/game-menu-architecture.md`、合规红线（ISO 4217 代码、几何母题非真币、静态汇率+免责、区域双编码）

---

## 1. 结论先行：蓝海判断是否成立？

**基本成立，但需加两道"护栏"。**

- ✅ **全球多国纸币+硬币「收藏 + 文化科普 + 休闲配对」组合，在微信小游戏里确实空白**。检索到的直接同类几乎都是：海外俄语/英语区答题 App（非微信、非中文、用真币图）、安卓单机 quiz、或收藏工具类 App。
- ⚠️ **护栏一（认知污染）**：微信小游戏里的"货币/硬币"关键词下，绝大多数是**红包/赚钱版克隆**（合硬币、与鱼同乐、天天爱消除红包版…），用硬币当代币做现金提现。我们必须从文案、视觉、玩法上**明确划清"教育/文化休闲"与"赚钱提现"的边界**，否则会被平台审核与玩家直觉一起归入垃圾池。
- ⚠️ **护栏二（合规边界）**：用户原调研建议的"拼真实纸币碎片、区分真假币"**不可行**——真实钞币图像涉及版权（各央行拥有票面设计权）+《人民币管理条例》反假币条款 + 金融安全敏感区，且"防伪/真假币"恰是央行、招行等机构的垄断科普阵地。差异化必须**留在几何母题 + 文化知识的合规信封内**。

| ------------------------------- | ------------------------------------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------- |

## 3. 直接竞品画像（决定我们怎么打）

### 3.1 《疯狂猜货币》—— 头号对标

- 强项：200+ 币种、知识卡、动态难度、好友对战、AR 扫真币、积分换实体货币模型。
- 致命弱点（我们的机会）：
  1. **真实钞币图像** → 版权 + 反假币灰色地带，微信小游戏过审风险高；
  2. **安卓单机、非微信生态** → 不占微信流量；
  3. **打字拼国名 / 限时答题** → 对儿童、休闲、碎片时间不友好；
  4. **奖励=积分/排行**，不是"长出来的收藏物"。

### 3.2 微信"红包/赚钱"克隆 —— 认知对手

- 合硬币、与鱼同乐等：硬币=代币、做任务提现。**不是竞品，是我们要远离的泥潭**。
- 风险：微信对"提现/红包/赚钱"机制审核极严；若我们的广告变现被误读为"赚钱游戏"，会触发审核与口碑双杀。

### 3.3 我们 vs 对标（一句话）

> **微信小游戏里第一款以「全球钱币收藏册」为元循环的休闲配对游戏**——风物志式自动收集 + 合规风格化美术 + 中文母语科普，避开红包/赚钱泥潭与真假币敏感区。

## 4. 机制护城河：自动收藏（用户已拍板）强化了差异化

用户刚定的"首次配对成功即自动收藏"机制，是相对所有答题竞品的**结构性优势**：

- 答题竞品奖励「分数/排行」→ 玩家离开即忘；
- 我们奖励「长出来的收藏册」→ 每次配对都往图鉴/档案里填一格，元循环自驱。
- 这把《原神》风物志的逻辑搬进休闲配对，且**零额外操作摩擦**（无"加入收藏"按钮），对儿童+成人都友好。
- 配合"未解锁=剪影占位"，天然制造回访动机——这是 quiz 类做不到的。

## 5. 合规信封内的可差异化方向（替代"拼真币/真假币"）

| 用户原建议             | 判定                | 合规替代                                 |
| ----------------- | ----------------- | ------------------------------------ |
| 拼纸币碎片             | ❌ 需真实票面图          | ✅ **拼「风格化几何母题」碎片**（自有美术，安全、可做成解压小游戏） |
| 区分真假币             | ❌ 撞央行/招行垄断 + 反假币法 | ❌ 不做；文化科普只讲"设计/历史/人文"，不碰防伪鉴别         |
| 汇率小问答             | ✅ 可行              | ✅ 用静态快照 + "非金融建议"免责，做轻量知识题           |
| 自建虚拟展览馆 / 3D 旋转查看 | ✅ 可行              | ✅ 旋转查看**风格化几何母题**正反面，沉浸但安全           |
| 钱币识图闯关            | ✅ 可行（但用几何母题）      | ✅ 识别"我们的风格化母题+ISO 码"，非真实钞币           |

> 一句话：**所有差异化都建立在"我们自己的风格化资产 + 文化知识"之上，绝不依赖真实钞币图像。**

## 6. 风险清单

1. **平台合规**：微信严审"提现/红包/赚钱"——广告变现须明示为"旅游主题内容赞助"，不暗示赚钱；文案禁用"赚、提现、红包"等词。
2. **认知混淆**：必须视觉/文案上与红包赚钱克隆划清界限（我们的暖色旅行行囊调性本身就是区隔）。
3. **内容准确性**：定位"教育/文化"，货币历史/人文知识点须事实准确（非金融建议，但知识要靠谱）。
4. **真实图像版权**：即便外国货币真实图也可能触版权+反假币；几何母题路线已被验证为最稳妥。
5. **留存**：纯配对长期留存弱——靠自动收藏图鉴 + 区域成就 + 未来护照章节驱动回访（meta 循环是核心壁垒）。
